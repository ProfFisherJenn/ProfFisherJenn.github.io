Image Size Explorer

Student:

In the Pixel Smiley Lab, the canvas never changed size. Real images do. Here you'll use a working copy of Photoshop's Image > Image Size dialog and watch what happens to the pixels and the physical size when Resample is on or off.

Resample uncheckedRearranges the pixels you have. The size in inches changes; the pixel count stays the same.
Resample checkedAdds or removes pixels. Use it to enlarge or reduce. Adding pixels never adds detail.
The equationsNumber of Pixels ÷ Resolution = Inches
Inches × Resolution = Number of Pixels
Real-world resolutions72–96 ppi for screens · 200 ppi for print · 300 ppi for high-quality and glossy print. The smiley scenarios use 5–25 ppi only so you can see the pixels.

Before you resize anything, ask what you need to keep. Keep the pixels and Resample stays off. Need more or fewer pixels and Resample goes on. More pixels from resampling up never bring back detail that wasn't captured.
